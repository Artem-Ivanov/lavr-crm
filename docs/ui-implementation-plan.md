# Схема системы и простой UI

Стек согласован: Vue 3 + Vite для витрины и CRM; FastAPI + PostgreSQL для будущего backend. 1С подключается серверным адаптером. Оплата и SEO отложены.

1. Подготовить SVG и Mermaid: два интерфейса → FastAPI → каталог, заказы, клиенты → PostgreSQL; outbox → worker → адаптер → 1С.
2. Изучить три сайта-примера и зафиксировать конкретные решения для поиска, каталога и CRM.
3. Перенести существующий рабочий сценарий на Vue SFC. Повторно использовать каталог, расчёты корзины, проверки контактов и переходы статусов.
4. Заменить демонстрационный static server на Vite; обновить entrypoint, npm scripts, зависимости и README. Удалить старый server и проверки его неактуального контракта.
5. Проверить доменные правила, production build, сценарий каталог → корзина → заказ → CRM, клавиатуру, ошибки browser storage и мобильную ширину.

Затронутые места: `src/app.js` → `src/App.vue`/`src/main.js` и небольшие компоненты; `index.html`, `package.json`, lockfile, Vite config; `server.mjs` и его тесты; browser smoke; README, архитектура и дизайн. Данные demo остаются в прежних ключах браузера. Корзина сохраняется при ошибке записи заказа. Пользовательские строки выводятся текстом Vue.

Backend, авторизация менеджера и реальная синхронизация не реализуются в рамках этого UI. Их границы и HTTP-контракт описаны в документации.
