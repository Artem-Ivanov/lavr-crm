# Сведения о производителе и стране

Пакет [open-catalog-2026-11-10.json](../catalog/enrichment/open-catalog-2026-11-10.json)
содержит результаты проверки 111 позиций исходного PDF: LAVR, NGK, DENSO,
ЛУКОЙЛ, FILTRON и SINTEC. Для 70 позиций подтверждены сведения для карточки,
41 требует проверки. Остальные 24 578 позиций еще не исследованы.

Для шести товаров LAVR официальный документ подтверждает юридического
изготовителя и российский адрес производства. Для остальных подтвержденных
позиций установлена только марка собственного продукта. В карточке она
обозначается «Марка производителя»; юридическое лицо и завод не подставляются.
Неизвестная страна не отображается. Страна головного офиса, марка автомобиля,
префикс штрихкода и адрес поставщика не служат подтверждением места изготовления.

Каждая строка хранит исходные имя, артикул и бренд, ссылки на первичные
источники, подтвержденные поля и причину решения. Дата проверки — 10 ноября 2026.
Старый артикул или отличающаяся фасовка не заменяются текущим аналогом.
Найденные факты описывают изделие по документации; соответствие конкретной
складской партии при сомнениях проверяется по ее маркировке.

Сведения добавляются к `ProductPresentation.websiteDescription` через существующий
API редактирования карточки. Сохраняются исходное описание, предупреждения о
состоянии и иллюстрации. Цена, остаток, артикул, учетный бренд, категория, название
и медиа не меняются. Отдельная миграция БД не требуется. Обычный импорт остатков
сохраняет редакторское описание.

Перед применением проверяются SHA исходного PDF, связь позиции с товаром из
журнала импорта, точные имя/артикул/бренд и исходное описание. Все строки пакета
проверяются до первой записи. Обновление отправляет только `websiteDescription`,
с текущей версией `If-Match` и CSRF-защитой. Уже совпадающее описание повторно
не записывается. При измененной вручную карточке пакет останавливается для проверки.

Применение данных выполняется отдельно от Git-деплоя кода. Исходный одноразовый
инициализатор каталога `app.catalog_release` повторно для этого пакета не запускается:
его проверка ожидает первоначальные описания. Пакет проверяется на тестовой БД;
публикация на production выполняется после пользовательского push в master.
