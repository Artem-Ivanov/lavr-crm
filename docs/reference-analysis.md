## Наблюдения

### ABCP

На просмотренной главной: светлый серо-голубой фон, отдельная белая шапка, скруглённые блоки, контрастный синий главный блок, крупные заголовки и белые карточки продуктов. Действия выделены цветом и размером; между блоками есть заметное свободное пространство. Это подтверждено [скриншотом главной](references/abcp-desktop.png) и [скриншотом страницы магазина](references/abcp-store-desktop.png). Источник: [главная ABCP](https://www.abcp.ru/).

Публичная [страница интернет-магазина](https://www.abcp.ru/online-store) описывает поиск по артикулу, фильтры и сортировку результатов, каталоги, обработку заказов и интеграцию с 1С. Умный поиск по VIN, платежи и другие возможности платформы выходят за согласованный MVP. [Страница программы для магазина](https://www.abcp.ru/store) связывает заказы, клиентов, статусы и последующие операции. Табличный вид нашей CRM — наше проектное решение; закрытый интерфейс ABCP не исследован.

### Автоприрода

В индексированном содержимом [каталога двигателя УАЗ для Ярославля](https://yarsl.autopriroda.ru/catalog/uaz/dvigatel_uaz/) видны категории, сортировка, фильтр брендов, артикул, цена за штуку, остаток числом или сообщение об уточнении наличия, количество и добавление в корзину. [Региональная главная](https://yarsl.autopriroda.ru/) содержит популярные категории и быстрый просмотр товаров. Это функциональные наблюдения по тексту индекса; цвет, сетку и типографику сайта не оценивали. [Снимок ограничения доступа](references/autopriroda-access-challenge.png) не является образцом дизайна.

### Арсенал Авто

Не удалось загрузить [указанную главную](https://arsenalavto-sm.ru/). Сайт остаётся пользовательским референсом, но решения нашего MVP не приписываются ему.

## Решения для простого UI

| Компонент схемы | Экран | Что показываем |
| --- | --- | --- |
| Каталог | Витрина и список товаров | Заметный поиск по артикулу или названию; категории; бренд; наличие; сортировка по цене. |
| Товар | Карточка и быстрый просмотр | Фото, название, бренд, артикул, цена, доступный остаток и срок; действие «В корзину». |
| Корзина и заказы | Корзина → контактная форма → результат | Количество с ограничением остатка, сумма, контакты, самовывоз или доставка; оформление заявки без платежей. |
| Заказы и клиенты | CRM менеджера | Таблица заказов, поиск, фильтр статуса; карточка заказа с контактами, составом и доступными следующими статусами. |
| Интеграция | Блок состояния обмена в CRM | Честный статус «1С не подключена» и объяснение роли серверного адаптера. Успешная синхронизация и реальные остатки 1С не имитируются. |

Сохраняем собственный красный акцент LAVR, нейтральный фон, белые блоки и ясную иерархию. Для витрины используем изображения товаров; для CRM — компактные строки и статусы. Главный поиск доступен сразу, оформление не требует длинной регистрации. На узком экране фильтры располагаются над адаптивной сеткой карточек; таблица CRM может прокручиваться внутри своего блока.

UI реализуется на согласованных Vue 3 + Vite. Связь с FastAPI и работа адаптера 1С остаются следующим этапом: в текущем UI используются демонстрационные данные. VIN-подбор, внешние поставщики, оплаты, финансовый учёт и SEO не входят в эту реализацию.
