# План реализации LAVR MVP

**Цель:** рабочий локальный фронтенд витрины и CRM без оплаты с документированной архитектурой интеграции 1С.

**Спецификация:** [mvp-design.md](mvp-design.md). Архитектура: независимые доменные модули каталога, корзины и заказов; интерфейс подключает их напрямую в деморежиме. Выбранный пользователем стек рабочей версии — FastAPI + Vue 3 + Vite, PostgreSQL, SQLAlchemy/Alembic, Python worker и отдельный адаптер 1С с transactional outbox. SEO отложено до следующих этапов; Nuxt не входит в MVP.

## Критичные случаи

Недоверенное browser storage не может добавлять неизвестные товары, отрицательное количество или клиентский денежный итог. Изображения иллюстративные, совместимость по автомобилю не обещается. Ошибка сохранения заказа оставляет корзину. Оформление имеет защиту от двойного нажатия и серверную идемпотентность. Docker-сборка предоставляет настоящий API на локальном интерфейсе; публикация CRM в интернет не выполнялась. До настройки адаптера 1С приём заказов заблокирован.
