# Полная локальная сборка

Реализовать существующий OpenAPI на FastAPI/PostgreSQL и запускать Vue/Nginx, backend и PostgreSQL через Compose. Данные сайта и файлы сохраняются в volumes; frontend работает в API-режиме. Конфигурация 1С неизвестна: отдельный отключённый адаптер честно сообщает `not_connected`, приём заказа до подключения возвращает `503` по принятому контракту, без фиктивного экспорта.

1. Общая основа: Python3.13, FastAPI, SQLAlchemy2/psycopg, Alembic, PostgreSQL17. Обязательные секреты, bootstrap администратора, серверные сессии/роли, CSRF/Origin, безопасные ошибки и версии.
2. Каталог: серверные категории, учётная проекция и отдельные поля оформления, поиск/фильтры/пагинация, видимость и атомарные версии. Исходный пример каталога включается явно только для локального просмотра.
3. Контент: настройки/меню, публикации и даты, защищённая медиабиблиотека, декодирование/лимиты файлов, публичная выдача по текущим ссылкам, сохранение данных и файлов при перезапуске.
4. Заказы: серверные цены, транзакции/идемпотентность/локальные резервы/outbox, роли и допустимые статусы. Адаптер 1С имеет отдельную границу; runtime не притворяется настроенной 1С.
5. Контейнеры: frontend API, backend, PostgreSQL, DB/media volumes и healthchecks. Генерация локальных секретов без установки Python на принимающем устройстве. Демо frontend остаётся явным выбором.
6. Проверки: реальные PostgreSQL-тесты доступа/конфликтов/видимости/заказов, API браузер без intercept, сохранность после пересоздания контейнеров, архив всех необходимых образов и запуск из чистого каталога.

Владение: root — общая основа/auth, миграции, Compose/образа, интеграция и документация. Отдельные implementers — каталог, контент/медиа, заказы/адаптер и собственные тесты. Общие интерфейсы: `app.db.Base`, `get_db()`, `SessionLocal`; `app.auth.get_current_staff`, `require_admin`, `require_mutation`, `require_admin_mutation`; `app.common.ApiError`, `version_header`, `check_version`, `page_response`, `utcnow`. Каждый route самостоятельно commit-ит успешную транзакцию. Модели регистрируются импортом доменных modules до миграции.

Секреты в ignored `.env.docker`; контейнеры/архив не содержат пароль bootstrap. Рабочий импорт/экспорт 1С и SEO не входят в эту сборку без необходимой конфигурации.
