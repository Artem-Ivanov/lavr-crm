## Сетевая конфигурация

Сервис слушает IPv4 `157.228.152.84:50051` с TLS. Отдельное правило UFW разрешает этот порт источнику `157.228.139.156`. API и будущий worker CRM используют общий readonly CA mount. Собственные credential источника и destination alias `mirzap67.staff` настроены; bot token удалён из действующего окружения CRM.

Выбран host networking: существующие Docker/VPN-сети и демон не перестраивались. Поведение host mode и опубликованных Docker-портов описано в [официальной документации Docker](https://docs.docker.com/engine/network/drivers/host/) и [документации по firewall](https://docs.docker.com/engine/network/packet-filtering-firewalls/).

Доступ с CRM подтверждён. Отрицательная проверка из отдельного Docker bridge-источника завершилась отказом/таймаутом. Рабочая станция выходит через этот же VPN-хост, поэтому её первоначальное соединение оказалось локальным для сервера. Проверка с независимого внешнего публичного адреса не выполнялась.

Сертификат сервиса действует до **28.01.2027 12:35 UTC**; его нужно обновить до этой даты. Закрытый ключ CA остаётся только локально.
