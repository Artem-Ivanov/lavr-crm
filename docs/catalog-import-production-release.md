Дата: 02.11.2026. Релиз: `catalog-20261102t165715z`.

Обновлена CRM на `157.228.139.156`, публичный сайт — https://mirzap67.ru. Импорт доступен администратору по https://mirzap67.ru/#crm-catalog через кнопку «Импорт PDF».

- Применены миграции 0007/0008; рабочая схема — 0008.

- Рабочий файловый импорт использует общую сверку с подготовленным портом будущего адаптера. Реальный адаптер учётной системы остаётся отключённым.

## Сохранность и проверки

Перед миграциями сайт переводился в режим обслуживания, запись останавливалась. Проверены резервное восстановление в отдельную временную БД и содержимое архивов исходников/медиа; зашифрованная копия успешно скачана и аутентифицирована локально. Размер — 12 623 788 байт; SHA-256 `5d606b6e9a23ae87d047f9576af578c417f0320028764a1da2670e4cee7e6ba2`.

Все прежние 22 таблицы проверены до открытия трафика. Сохранены пользователи и пароли, данные/последовательности, 6 категорий, 3 публикации и 10 медиафайлов. `.env.docker`, ключи PII/сессий, настройки relay/CA и HTTPS не менялись; контейнеры и тома PostgreSQL/Caddy сохранены.

После открытия HTTPS проверены:

- Публичные данные сайта и хеши четырёх используемых медиа не изменились.
- Существующий администратор входит с прежними реквизитами и получает все три административных права.
- Окно импорта открывается при ширине 1440/390/320 px, поддерживает Escape и возвращает фокус.
- API подтверждает PDF до 5 МиБ, 400 страниц, 50 000 строк и единицы шт/кг/л/м.
- Нативная библиотека PDFium 5.14.0 загружается непосредственно на VPS; серверный health возвращает 200, анонимный доступ к административному импорту — 401.
- Четыре новые таблицы импорта и история пакетов пустые. Товаров, заказов и обращений — 0. Сам импорт в production не выполнялся: его вручную проверит владелец.
- Контрольная сессия закрыта: после выхода API возвращает 401, активных сессий не осталось. Допустимое изменение служебных журналов — две записи входа/выхода и обновление лимита входа; пользовательские данные не менялись.

Автоматические Telegram/email-отправки остались выключенными, соответствующие workers не запускались. Отдельный VPS notifier в этот релиз не обновлялся.

Защитная проверка Docker-томов один раз остановила установку до первой миграции из-за нестабильного порядка одного и того же списка Mounts. На 12 чтениях подтверждена идентичность всех путей и прав. Сравнение нормализовано по назначению, сохранив проверку всех полей и запрет дублей; исправление прошло отдельные регрессионные проверки и независимый просмотр до продолжения.

## Ручная проверка

Войдите существующим администратором, откройте «Каталог» → «Импорт PDF», выберите файл и фактическое время состояния склада. Проверьте единицы, категории, изменения и исключения перед применением. Инструкция: [catalog-import.md](catalog-import.md).

Оформление заказов без настроенной ERP остаётся заблокированным по существующей политике. Этот релиз не включает автономный приём/списание заказов и не помечает 1С подключённой.

Полные протоколы стадий, хеши образов/исходников и проверка браузера сохранены в локальном каталоге `.planning/2026-11-02-catalog-import-vps-release/`. После открытия трафика восстановление замороженной БД автоматически не допускается: новые пользовательские записи должны сохраняться.
