исходной строки. `image-prompts.json` содержит запросы генерации 225 общих

Время состояния склада — момент первой загрузки пакета. Единица по умолчанию
`шт`; только семь явных пометок «за 1кг»/«за 1м» задают пять позиций в `кг` и
две в `м`. Объём упаковки или размеры сами по себе единицу продажи не меняют.
Дробные остатки сохраняются без округления, отсутствующий остаток считается
нулём. Одинаковые названия с разными ценами остаются отдельными карточками.
Десять строк наборов/компонентов импортируются самостоятельными позициями.
Все 122 позиции с дробным остатком перечислены в [fractional-stock.csv](fractional-stock.csv)
с исходным названием, страницей PDF и основанием выбора единицы.

Исходные пометки о состоянии не убираются: три просроченных товара, шесть б/у и
два некомплектных дополнительно получают явную пометку в заголовке карточки.
Сырые названия, цены, артикулы и бренды берутся из PDF.

Порядок применения и границы отката: [catalog-data-release.md](../../../docs/catalog-data-release.md).
